# Changelog

## Version 1.1

- Pics de charge : les minutes où beaucoup de tâches partent ensemble sont
  signalées dans le calendrier et détaillées dans la journée (seuil réglable).
- Calcul plus rapide : commandes, équipements et objets lus par lots, et
  rangement par jour des tâches fréquentes allégé (environ trois fois moins de
  requêtes, près de deux fois plus rapide).
